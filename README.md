# Tarea 4

El proyecto tiene la estructura de carpetas requerida por Spring Boot.

- src/main/com/actividades: se definen las tablas, con sus repositorios y controladores. Las columnas vienen dadas por la base de datos. No guardé la fecha ni duración de las actividades porque de todas formas no se usaba para nada.
- src/main/resources/js: todos los archivos javascript. Los archivos antiguos tienen pequeños ajustes, y los nuevos fueron creados para hacer lo que antes se hacía en flask.

Para ejecutar escribir en la terminal: ./mvnw spring-boot:run
